# Замечания и доработки

Этот документ фиксирует моменты, которые нужно поправить на сайте.

## 1. Визуальные моменты

### 1.1. Блок «Услуги»
Сейчас услуги просто перечислены текстом . По задумке к каждой должна быть картинка или иконка — так блок выглядит легче и понятнее.

**Что сделать:** Добавить к каждой услуге небольшую иконку. Например, для мойки — форсунка, для керамики — щит.

Ещё в ТЗ было предложение добавить блок «Часто заказывают вместе», чтобы клиент брал больше услуг. Сейчас этого нет.

**Что сделать:** Под услугами добавить рекомендации вроде «Дополните керамику антидождём со скидкой». Это помогает увеличить средний чек.

---

### 1.2. Блок «Результаты работ»
Сейчас там просто список машин и их фото. Но по ТЗ здесь должен быть интерактивный слайдер «До/После» — это самый сильный инструмент, который показывает качество работы.

**Что сделать:** Вместо списка сделать карусель с фото «до» и «после» для каждой машины. Идеально — чтобы можно было двигать ползунок и сравнивать в одном кадре. Под фото написать, что делали с машиной.

---

### 1.3. Блок «Контакты и карта»
На карте видны чужие организации («ТАФИ Диагностика», «Биллис паб»). Это отвлекает и выглядит неопрятно.

**Что сделать:** Настроить карту так, чтобы метка была строго на адресе ул. Острякова, 49, а лишние названия убрать.

---

## 2. Функциональные моменты

### 2.1. Форма обратной связи
Сейчас поля никак не проверяются. Можно отправить пустую заявку или написать что угодно.

**Что сделать:**
- Сделать поля в поле имя только буквы, а в поле с телефоном только цифры
- Для телефона добавить маску, чтобы номер вводился в формате +7 (___) ___-__-__.


---

### 2.2. Навигация (меню)
На мобильных будет бургер-меню. Нужно учесть два момента:
- После того как человек нажал на ссылку в меню, меню должно само закрываться.
- При переходе по ссылке заголовок блока не должен прятаться за шапкой сайта.

**Что сделать:**
- Добавить скрипт, который закрывает бургер после клика по ссылке.
- Для всех блоков добавить отступ сверху, чтобы они не перекрывались шапкой.

---

## 3. Производительность

### 3.1. Изображения
На странице много фото автомобилей. Если не сжать их, сайт будет грузиться долго.

**Что сделать:**
- Сжать все картинки.
- Использовать современный формат WebP (он весит меньше).
- Настроить загрузку разных размеров фото для телефонов и компьютеров.

---

### 3.2. Адаптивность на телефонах
На очень узких экранах (например, iPhone SE) текст может вылезать за края.

**Что сделать:**
- Уменьшить заголовки на телефонах, чтобы они помещались.
- Блок с преимуществами («Премиум-материалы», «Гарантия результата») на телефоне сделать в одну или две колонки, чтобы текст читался нормально.

---

## 4. SEO

### 4.1. Мета-теги
Чтобы сайт находили в поиске (Яндекс, Google) и он красиво отображался в соцсетях, нужно добавить мета-теги.

**Что сделать:**
- Добавить заголовок страницы (title) с ключевыми словами: «Профессиональный детейлинг во Владивостоке | Защита авто».
- Добавить описание (description), которое будет видно в поисковой выдаче.
- Настроить OG-теги, чтобы при отправке ссылки в Telegram или WhatsApp показывалась красивая картинка.

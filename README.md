# 🚗 Premium Detailing Vladivostok

Современный лендинг для **премиального детейлинг-центра во Владивостоке**.  
Проект демонстрирует услуги по уходу за автомобилями с акцентом на стиль, удобство и визуальную презентацию результатов.

---

##  Особенности проекта

-  **Современный дизайн** — тёмная тема с золотым акцентом `#d4a017`
-  **Адаптивная вёрстка** — корректное отображение на всех устройствах
-  **Видео-фон** — замедленное видео (0.5x) процесса мойки в hero-секции
-  **Форма обратной связи** — интеграция с **EmailJS**
-  **Фотогалерея "До / После"** — демонстрация результатов работы
-  **Плавная навигация** — переходы между секциями через `react-scroll`

---

# 🛠 Технологический стек

| Технология | Назначение |
|---|---|
| **React 18** | Создание пользовательского интерфейса |
| **TypeScript** | Типизация и надёжность кода |
| **Vite** | Быстрая сборка и dev-сервер |
| **SCSS** | Стилизация через препроцессор |
| **React Hook Form + Yup** | Валидация формы |
| **EmailJS** | Отправка заявок без backend |
| **React Icons** | Иконки интерфейса |
| **React Scroll** | Плавная навигация |

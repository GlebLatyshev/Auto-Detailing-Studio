# 🚗 Premium Detailing Vladivostok

Современный **лендинг для премиального детейлинг-центра во Владивостоке**.  
Проект демонстрирует услуги автодетейлинга, результаты работ и предоставляет удобную форму для отправки заявок клиентами.

Сайт выполнен в **тёмной премиальной стилистике с золотым акцентом**, имеет адаптивный дизайн и современную архитектуру на React.

---

#  Особенности проекта

-  **Современный дизайн** — тёмная тема с золотым акцентом `#d4a017`
-  **Адаптивная вёрстка** — корректная работа на мобильных устройствах, планшетах и ПК
-  **Видео-фон** — замедленное видео процесса мойки (0.5x) в hero-секции
-  **Форма обратной связи** — интеграция с EmailJS для отправки заявок
-  **Галерея "До / После"** — демонстрация результатов детейлинга
-  **Плавная навигация** — скролл между секциями через `react-scroll`

---

#  Технологический стек

| Технология | Описание |
|---|---|
| **React** | библиотека для создания интерфейсов |
| **TypeScript** | строгая типизация |
| **Vite** | быстрый сборщик и dev-сервер |
| **SCSS** | препроцессор для стилизации |
| **React Hook Form + Yup** | валидация форм |
| **EmailJS** | отправка заявок без бэкенда |
| **React Icons** | иконки интерфейса |
| **React Scroll** | плавная навигация |
| **Google Maps API ** | API с картой, на которой показнно место положения дитейлинга |

#  Установка и запуск

## 1. Клонировать репозиторий

```bash
git clone https://github.com/yourusername/premium-detailing.git
cd premium-detailing
2. Установить зависимости
npm install
3. Запустить проект
npm run dev

После запуска проект будет доступен по адресу:

http://localhost:5173
```

##  Структура секций

### 1. **Hero (Главный экран)**
- Фоновое видео процесса мойки (замедлено 0.5x)
- Градиентный overlay для улучшения читаемости текста
- Кнопка призыва к действию (CTA): запись на услугу

### 2. **Services (Услуги)**
- Карточки услуг с изображениями
- Краткое описание каждой услуги


### 3. **Before / After (До/После)**
- Галерея с результатами работ
- Визуальное сравнение 
- Подписи с описанием выполненных работ

### 4. **Contacts (Контакты и запись)**
- Форма обратной связи (имя, телефон)
- Валидация формы: `react-hook-form` + `yup`
- Отправка данных: `EmailJS`
- Интерактивная карта **Google Maps** с меткой дитейлинга
- Карта адаптируется под мобильные устройства
